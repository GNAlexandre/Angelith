# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1**, as its code of conduct.

The full text is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/> and is available in
[many translations](https://www.contributor-covenant.org/translations/). It is used here under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), as its authors intend.

In short: everyone is welcome regardless of who they are; harassment, insults, and
personal attacks are not tolerated; maintainers are responsible for enforcing this and may
remove contributions or contributors that violate it.

## Scope

It applies in every project space — repository, issues, pull requests, discussions — and
whenever someone is representing the project in public.

## Reporting

Report unacceptable behaviour to **tournelalexandre@gmail.com**. Reports are handled
confidentially, and you will get a reply within **7 days**. The maintainer is a single person,
not a committee: if the report concerns the maintainer and you would rather not write to them
directly, say so publicly in an issue, or use the Contributor Covenant's guidance on escalation.
