# Dépendances Python
# ⚠ PLAFONNÉ SOUS 3.0, et ce n'est pas de la frilosité. `openai` 3.x est bâti sur **httpx2**,
# pas sur httpx. Or `core/llm.py` construit lui-même son `httpx.Timeout` — tout le
# dimensionnement dérivé de `DEBIT_PLANCHER_DEFAUT` en dépend. Passé à un client httpx2, cet
# objet atterrit dans un emplacement qui en attend un autre : la configuration résultante est
# malformée au point que son `repr` lève `TypeError: unhashable type: 'Timeout'`.
#
# C'est précisément le défaut contre lequel `LLM.__init__` met en garde — un plafond de durée
# retiré SILENCIEUSEMENT — et aucun test ne peut l'attraper, tous doublant le client. Lever le
# plafond demande de porter `core/llm.py` sur httpx2 délibérément, pas de laisser pip décider.
#
# Ce que le socle porte — les lignes d'origine, gardées en prose, et le plafond ci-dessus est
# recopié TEL QUEL dans `pyproject.toml` :
#   openai>=1.40,<3      client compatible LM Studio / Ollama
